`C#` `EF Core` `MySQL` `Angular` `Docker` `CI/CD`

</td>

<td width="50%" valign="top">

Criptoanálisis automático de **César, Afín y Vigenère** por índice de coincidencia. Login con **bcrypt**, sesiones y **protección contra fuerza bruta**, desplegado en **AWS EC2 + nginx** con Let's Encrypt configurado manualmente.

`TypeScript` `Angular SSR` `Express` `MySQL` `AWS` `TLS`

`C#` `.NET` `AST` `Graphviz`
